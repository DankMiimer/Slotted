## Can the theme be open source?

**The code can be open source while assets keep separate licenses.** Purchasing
a model does not let us relicense it as MIT. CGTrader's ordinary terms restrict
distribution to incorporated products and require reasonable protection against
end-user access in software. A repository containing openly reusable purchased
meshes is not supported by those standard terms; it needs separate written
redistribution rights. Keep such models out of the public asset repository unless
those rights are obtained. See [CGTrader terms, definition 8 and sections 20-21](https://www.cgtrader.com/pages/terms-and-conditions).

For openly reusable asset files, prefer **CC0, CC BY or CC BY-SA**, preserving the
original notices and applicable conditions. CC BY requires credit, license/source
links and change notices. ShareAlike applies to adapted assets under its terms;
do not relabel those assets MIT. See [CC BY](https://creativecommons.org/licenses/by/4.0/),
[CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/) and [CC0](https://creativecommons.org/publicdomain/zero/1.0/).

**Keeping the current N64 is compatible with publishing open-source code plus a
separately licensed noncommercial asset.** Its CC BY-NC-SA 4.0 terms allow sharing
and adaptation with attribution, noncommercial use and ShareAlike conditions.
They do not permit unrestricted commercial reuse. Therefore describe that edition
as open-source code with separately licensed/noncommercial art, not a uniformly
MIT-licensed asset collection. See [the actual NC-SA conditions](https://creativecommons.org/licenses/by-nc-sa/4.0/)
and [the Open Source Definition](https://opensource.org/osd) for the distinction.

The existing [asset ledger](../CREDITS.md) also records noncommercial GB/TV/furniture
options and the **local-only editorial NeilVFX GBA SP**, already excluded from
the redistributable CC/MIT bundle. This task does not change their selection.
Those assets need correct separation/licensing in any actual release; this report
does not certify the whole current checkout for redistribution. Fixed game labels,
manufacturer artwork and trademarks are not automatically cleared by the model
creator's license. Keep the existing per-game artwork approach rather than shipping
the source's fixed game art as generic theme content.

# Console artwork

Original geometry and cel-shaded artwork, copyright 2026, MIT. See the theme's
LICENSE. These files contain no downloaded 3D models, photographs or game artwork.
Open Sans printed outlines are credited in `../fonts/OFL.txt`.

Sources and rebuild instructions: `tools/consolebuild/models.py` and
`tools/consolebuild/README.md` in the project repository. Each subdirectory contains
an editable full `model.glb`, the native indexed `model.mesh`, its geometry record,
and the matching idle preview. `specs.json` records the seating geometry.
